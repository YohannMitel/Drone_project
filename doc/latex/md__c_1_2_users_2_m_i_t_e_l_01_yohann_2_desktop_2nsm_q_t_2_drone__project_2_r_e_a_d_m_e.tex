This project involves the creation of a drone routing system using Voronoi diagrams to map and manage drone navigation between server areas. The system adheres to the specifications outlined in the project requirements and includes\+:


\begin{DoxyItemize}
\item A Git\+Hub repository with the full implementation.
\item Documentation and algorithm explanations.
\item A dedicated branch for the Voronoi diagram implementation.
\end{DoxyItemize}\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md2}{}\doxysubsection{\texorpdfstring{Initial Problem Statement}{Initial Problem Statement}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md2}
The initial data for the project was provided in {\ttfamily config1.\+json} and {\ttfamily config2.\+json}. Key features of the problem include\+:\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md3}{}\doxysubsubsection{\texorpdfstring{Servers and Voronoi Areas\+:}{Servers and Voronoi Areas\+:}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md3}

\begin{DoxyItemize}
\item Servers are identified by unique names.
\item Each server is associated with a colored area defined by a Voronoi diagram.
\item Servers are connected through a wired network, with connections existing when server polygons share a common edge.
\end{DoxyItemize}\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Drones\+:}{Drones\+:}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md4}

\begin{DoxyItemize}

\item Drones communicate only with the server associated with the zone they are flying over.

The Voronoi diagram forms the backbone of the mapping system, dividing the area into zones associated with each server. This process involves\+:\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md8}{}\doxysubsubsubsection{\texorpdfstring{Input Processing\+:}{Input Processing\+:}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md8}

\begin{DoxyItemize}
\item Input consisted of points rather than triangles.
\item Points were sorted using a polar angle in ascending order to prepare for convex hull construction.
\end{DoxyItemize}\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md9}{}\doxysubsubsubsection{\texorpdfstring{Convex Hull Construction\+:}{Convex Hull Construction\+:}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md9}

\begin{DoxyItemize}
\item The convex hull was constructed to define the boundary of the area.
\end{DoxyItemize}\hypertarget{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md10}{}\doxysubsubsubsection{\texorpdfstring{Triangulation\+:}{Triangulation\+:}}\label{md__c_1_2_users_2_m_i_t_e_l_01_yohann_2_desktop_2nsm_q_t_2_drone__project_2_r_e_a_d_m_e_autotoc_md10}

\begin{DoxyItemize}
