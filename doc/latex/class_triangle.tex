void Triangle\+::flipp\+It (\begin{DoxyParamCaption}\item[{QVector$<$ \mbox{\hyperlink{class_triangle}{Triangle}} \texorpdfstring{$\ast$}{*} $>$}]{triangles}{}\end{DoxyParamCaption})}



Flip the triangle with an adjacent triangle if possible. 

This function attempts to flip the current triangle with one of its neighboring triangles. A flip is only possible if the two triangles share a common edge, and the flip follows Delaunay\textquotesingle{}s criteria.

The function checks each of the three edges of the current triangle to find a common edge with an adjacent triangle. If the flip is successful, the vertices of both triangles are updated, and the circumcircle for both triangles is recalculated.
